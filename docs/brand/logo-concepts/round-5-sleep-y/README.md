# Round 5: Sleep Y

Four standalone Y logo directions for YBM:

1. `01-crescent-y.png` - crescent-moon silhouette and negative space.
2. `02-closed-eye-y.png` - a calm closed-eyelid curve flowing into the stem.
3. `03-pillow-fold-y.png` - broad pillow-like geometry with a soft fold accent.
4. `04-sleep-wake-y.png` - a subtle standby-ring gesture built into the Y.

Selected refinement:

- `03-pillow-y-simplified.png` - option 3 reduced to one chunky silhouette in a
  medium periwinkle-indigo chosen to stay calm without becoming too dark.

This refinement was selected and converted into the canonical production mark at
`../../ybm-mark.svg`.

These are raster concept explorations on white, not production logo masters.
